# AI Tutor Agent Project

## About This Project
This repository contains the code for a custom AI Tutor Agent designed for 7th and 8th-grade students. It features voice interaction, homework tracking, and an anti-distraction parent alert system.

## Developer Workflow Rules (STRICT)
1. **No Manual Copy-Pasting:** All code updates will be provided as downloadable files.
2. **Execution:** Files will be downloaded to the local machine and executed from the terminal.
3. **Clipboard Output:** All run commands will pipe output to the clipboard (e.g., `python main.py | clip`) for easy sharing of results or errors.
4. **Version Control:** After every successful run and verification, changes MUST be committed and pushed to the Git repository.

# VISION: Next-Gen AI Tutor Agent

## 1. Project Goal
To build a highly intelligent, interactive, and strict-yet-friendly AI Tutor for 7th and 8th-grade English medium students. The agent will eliminate the need for traditional extra tuition by acting as a personalized 1-on-1 teacher.

## 2. Target Audience
- **Primary Users:** Students in 7th and 8th grade.
- **Secondary Users (Monitors):** Parents who need assurance that their kids are studying effectively and not getting distracted.

## 3. Core Persona of the AI Tutor
- **Strict but Friendly:** approachable for doubts but maintains discipline.
- **Logical Verifier:** Does NOT blindly agree with the student. It analyzes the student's input and only agrees if the concept or answer is genuinely correct.
- **Guiding, Not Spoon-feeding:** Explains concepts in simple language but forces the student to think and solve the final piece of the puzzle.

## 4. Key Features & Capabilities
1. **Curriculum Database (1st to 12th Std):** Pre-trained knowledge of standard syllabus to seamlessly adapt to the students' daily school progress.
2. **Daily Revision & Homework Engine:** 
   - Takes daily input: "Today I learned [Topic] in [Subject]."
   - Generates customized revision questions and assigns homework based on the topic.
   - Evaluates completed homework and provides constructive feedback.
3. **Voice Command System:** Two-way voice interaction (like Gemini voice mode) for a natural, conversational teaching experience.
4. **Anti-Distraction & Parent Alerts:** 
   - Tracks app focus. 
   - If the student minimizes the app, closes it unexpectedly, or switches to a game/browser during study time, the system will immediately trigger an alert (SMS/WhatsApp) to the parents' mobile.

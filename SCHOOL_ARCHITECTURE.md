# GyanVerse Academy Architecture

```text
GyanVerse Academy
├── Principal Coordination
├── Class Teacher Guidance
├── Shared Teacher Engine
│   └── Subject Teacher Profiles
├── Student Analyzer
├── Teacher Reasoning Engine
├── Teaching Strategy Selector
├── Knowledge Graph
├── Learning Memory
└── Staff Room Collaboration
```

Teachers are validated profiles on one shared engine, not separate duplicated AI apps. Phase 6A adds identity, roles, profiles, routing, safe prompt generation, and tests. Live Gemini routing follows in Phase 6E after analyzer and reasoning contracts are stable.

# Parent, Guardian & Future Path Intelligence

## Purpose

This phase gives parents and guardians a privacy-safe way to understand a
child's learning through the Class Teacher and Principal.

It is designed to help adults support the child rather than force a subject,
stream, or profession.

## Guardian Capabilities

A guardian can ask:

- What did the child learn today?
- Which topics currently need support?
- Where is the child showing interest?
- What home activity would help?
- What broad exploration areas may be worth trying?

A single guardian profile may be linked to multiple children. Every child's
learning memory remains separate.

## Class Teacher Role

The Class Teacher provides:

- daily learning summary;
- current strengths;
- temporary support needs;
- interest signals;
- confidence support;
- practical home-support suggestions.

## Principal Role

The Principal provides:

- broader progress overview;
- long-term strength and interest patterns;
- balanced exploration suggestions;
- non-deterministic future-path guidance;
- reminders against forced career decisions.

## Privacy Rules

- Ordinary guardian reports exclude private student conversations.
- Sensitive emotional notes are not exposed automatically.
- Safety concerns use a controlled safeguarding escalation process.
- Guardians may only access linked children.
- Access is auditable.
- Least-privilege reporting is mandatory.

## Sibling Comparison Protection

The system does not rank siblings or classmates.

Instead, it explains each child's individual:

- strengths;
- interests;
- support needs;
- learning preferences;
- progress path.

## Future Path Guidance

The advisor distinguishes:

- interest;
- understanding;
- performance;
- persistence;
- voluntary exploration;
- preferred learning methods.

It outputs exploration areas and suggested activities. It never says that a
child must become a doctor, engineer, lawyer, or any other profession.

Every future-path response includes this principle:

> This is an exploration map, not a career decision.

## Safety Principles

- Never label a child permanently.
- Never equate marks with intelligence.
- Never decide a career from one test.
- Never shame the child.
- Never compare siblings.
- Respect the child's own preferences.
- Re-evaluate recommendations as new evidence appears.
